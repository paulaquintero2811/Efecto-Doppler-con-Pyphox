# Laboratorio: Comprobación del Efecto Doppler mediante Phyphox

## Descripción

Este repositorio contiene el desarrollo del laboratorio de Física enfocado en la comprobación experimental del efecto Doppler utilizando la aplicación **Phyphox**. El experimento consistió en registrar la variación de la frecuencia de una señal sonora de 1000 Hz cuando existía movimiento relativo entre una fuente emisora y un observador.

Para el desarrollo del laboratorio se emplearon dos teléfonos inteligentes. Uno que actuó como fuente sonora mediante la herramienta **Tone Generator** de Phyphox, mientras que el otro actuó como observador utilizando el experimento **Doppler Effect**.

Los datos obtenidos fueron exportados en formato CSV y posteriormente procesados en **MATLAB** y **Python**, con el fin de generar las gráficas de frecuencia y velocidad en función del tiempo y analizar el comportamiento del efecto Doppler.

---

## Objetivo

Comprobar experimentalmente el efecto Doppler utilizando la aplicación Phyphox y analizar los resultados obtenidos mediante herramientas de procesamiento de datos como MATLAB y Python.

## Procesamiento de datos

Los datos obtenidos por la aplicación Phyphox fueron exportados en formato CSV y procesados con ayuda de MATLAB y Python. Con estos programas se generaron las gráficas de:

- Frecuencia vs. Tiempo.
- Velocidad vs. Tiempo.

Luego, se realizó el análisis de los resultados para cada uno de los casos experimentales, comparando el comportamiento observado con la teoría del efecto Doppler.

---

## Resultados

Los resultados obtenidos permitieron comprobar experimentalmente el efecto Doppler. En ambos casos se observó que la frecuencia aumenta cuando la fuente y el observador se acercan y disminuye cuando se alejan, comportamiento que coincide con lo esperado teóricamente.

Además, el procesamiento realizado en MATLAB y Python nos arrojó resultado muy similares, validando el análisis de los datos obtenidos durante el experimento.
